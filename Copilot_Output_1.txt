### 2. Strategy Validation Routing Mechanism

To allow the bot to automatically validate each position against its specific strategy (e.g. `breakout` vs. `trend_following`), the class provides `resolve_strategy_type` using the following fallback hierarchy:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Strategy Resolution Order                       │
│                                                                        │
│  1. Explicit parameter: validate_position(..., strategy_type="breakout")│
│                         ▼ (if not provided)                            │
│  2. Position metadata:  pos["strategy"] == "breakout"                  │
│                         ▼ (if not tagged)                              │
│  3. Validator default:  Validation(strategy_type="breakout")           │
│                         ▼ (if "auto")                                  │
│  4. Indicator inference from DataFrame:                                │
│       • If 'DC_Upper' / 'DC_Lower' in df.columns ──> 'breakout'        │
│       • If 'EMA_20' in df.columns                ──> 'trend_following' │
└────────────────────────────────────────────────────────────────────────┘
```

#### How to use this in the Bot / Worker Thread:

1. **Option A (Automatic via DataFrame indicators or Position tagging - Recommended):**
   ```python
   # The bot calls the validator directly; it auto-routes based on the DataFrame's columns:
   validity = validator.validate_position(pos, price_df, current_market)
   ```

2. **Option B (Tagging the position dictionary when tracking trades):**
   ```python
   pos["strategy"] = "breakout"
   validity = validator.validate_position(pos, price_df, current_market)
   ```

3. **Option C (Dedicated Validator instances per Strategy):**
   ```python
   breakout_validator = Validation(strategy_type="breakout")
   trend_validator = Validation(strategy_type="trend_following")
   ```
